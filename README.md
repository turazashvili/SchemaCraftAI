# Schema Craft

Schema Craft is a powerful tool for database schema design and code generation.

## Project Overview

Schema Craft helps you quickly design database schemas and generate boilerplate code for various technology stacks. It streamlines the development process by allowing you to:

1. Design your database schema using natural language
2. Visualize your entities and relationships
3. Generate code for your chosen tech stack 
4. Download a complete bundle with models, routers, and schemas

## Technologies Used

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- ReactFlow

## Getting Started

To run this project locally:

```sh
# Step 1: Clone the repository
git clone https://github.com/turazashvili/SchemaCraftAI.git

# Step 2: Navigate to the project directory
cd SchemaCraftAI

# Step 3: Install the necessary dependencies
npm install

# Step 4: Start the development server
npm run dev
```

## Deployment on Vercel

This project is configured for easy deployment on Vercel:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fturazashvili%2FSchemaCraftAI)

1. **Push your code to GitHub**
   ```
   git add .
   git commit -m "Ready for deployment"
   git push
   ```

2. **Deploy to Vercel**
   - Create a Vercel account if you don't have one
   - Import your GitHub repository (SchemaCraftAI)
   - Vercel will automatically detect the Vite configuration
   - Click "Deploy"

3. **Environment Variables**  
   No special environment variables are required for basic functionality.

## Features

- **Natural Language Schema Generation**: Describe your database in plain English
- **Visual Schema Designer**: See and edit your database entities and relationships
- **Multiple Technology Stacks**: Generate code for TypeScript, JavaScript, Python, and more
- **Multiple Database Types**: Support for PostgreSQL, MongoDB, MySQL, and others
- **Code Generation**: Automatically create models, routes, and schemas
- **Auto-save**: All changes are automatically saved

## How to Use

1. Describe your database schema in the left sidebar
2. Review and modify the generated schema visualization
3. Select your preferred technology stack
4. Generate and download the code bundle
